# QQ 本地防撤回部署

面向 Windows x64 QQ `9.9.32-51246` 的 LiteLoaderQQNT 插件。插件只处理本机已经收到的消息，不修改 QQ 服务器状态或网络协议。

> 最新版本：**1.4.7**。查看 [更新日志](CHANGELOG.md) 或 [GitHub Releases](https://github.com/sanha233-lab/qq-local-recall/releases)。

## 功能

- 保留文字、QQ 原生小表情、回复、混合消息，以及普通图片、图片/动画表情和商城表情；优先保存 QQ 本机 `appimg:` 原始动画字节，本地副本不可用时默认通过当前 QQ 会话受限回源，最后才保存已加载完成且比例匹配的静态 PNG。
- 语音防撤回：撤回的语音消息保留可播放的播放条（含时长）。
- 撤回提示按消息类型区分：语音显示”尝试撤回此语音”，图片显示”尝试撤回此图片”，其他消息显示”尝试撤回此消息”。
- 撤回提示显示真实操作者；普通成员显示”成员名 尝试撤回…”，管理员或群主撤回他人消息时同时显示角色、操作者和原发送者。
- 已撤回记录跨 QQ 重启保留。
- 按好友或群聊显示记录数、实际文件占用和最后撤回时间。
- 好友缺少昵称时显示可读的“好友（QQ号）”，不直接展示 QQ 内部 UID。
- 管理页面显示当前记录目录，支持选择新的本机磁盘目录并迁移已有记录及仍被引用的媒体。
- 按占用降序排列，支持搜索、勾选并整组删除；删除最后一条引用时同步清理对应媒体文件。
- 管理页展开会话可逐条查看与删除记录，并预览内容：文字片段、语音时长、图片缩略图。
- 默认不阻止自己撤回消息。
- 插件没有第三方运行时依赖或原生模块；仅缺失图片恢复会复用当前 QQ 窗口的登录会话请求 QQ 媒体服务，可在管理窗口关闭。

## 不支持

- 本地副本、有效临时媒体地址和 Canvas PNG 均不可用的图片/表情，以及视频、文件、转发记录和复杂卡片恢复。
- 插件安装前、QQ 离线期间已经完成的撤回。
- QQ 更新到新版本后的自动适配（版本与已验证基线不一致时，管理页会显示提醒但不阻止运行）。

## 使用

1. 完全退出 QQ。
2. 以 PowerShell 运行交付目录中的 `install.ps1`。
3. 启动 QQ，在“设置 > QQ 本地防撤回”中打开记录管理。
4. 如需恢复原状，完全退出 QQ 后运行 `rollback.ps1`。

详细说明见 [docs/installation.md](docs/installation.md)。

记录保存位置可在“管理记录”窗口中查看并修改；媒体保存在当前记录根目录的 `media/`，单项上限 20 MiB，并按 SHA-256 去重。“缺失媒体自动回源”默认开启，关闭后只使用 QQ `Pic/Emoji` 本机原件或有效 Canvas；临时 URL、`fileid` 和 `rkey` 不写入记录或日志。
